# SQL Assignment — Retail Sales Database
**Author: Collins Njeru**


## Overview

This assignment explores a simulated retail database using PostgreSQL. It covers 139 queries across a four-table schema — `customers`, `products`, `sales`, and `inventory` — with 50 customers, 15 products, and 15 sales transactions.

## What's Covered

- **Basic Queries** — SELECT, WHERE, ORDER BY, aggregates (SUM, AVG, COUNT, MAX, MIN)
- **JOINs** — INNER, LEFT, and self-joins across multiple tables
- **Subqueries** — correlated and non-correlated nested queries
- **CTEs** — WITH clauses for readable multi-step logic
- **Window Functions** — RANK, NTILE, LAG, LEAD, running totals
- **CASE WHEN** — conditional labelling (price tiers, customer levels, stock status)
- **Date Functions** — EXTRACT, TO_CHAR, DATE_TRUNC
- **NULL Handling** — COALESCE, IS NULL, TRIM, LOWER
- **Stored Functions & Procedures** — reusable PL/pgSQL logic
- **Indexes, Views, Transactions, Set Operations** — production-level SQL practices
- **Bug Fixes** — correcting common GROUP BY, HAVING, and JOIN mistakes

## Database
Schema: `assignment` | Tables: `customers`, `products`, `sales`, `inventory`
